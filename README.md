# Vanelogg – publisering på GitHub Pages

1. Opprett et nytt repo på github.com (f.eks. `vanelogg`).
2. Last opp alle filene i denne mappen til roten av repoet (Add file → Upload files).
3. Repo → Settings → Pages → Source: «Deploy from a branch», Branch: `main`, mappe `/ (root)` → Save.
4. Etter ca. et minutt er appen på `https://<brukernavn>.github.io/vanelogg/`.
5. På mobilen: åpne adressen → «Legg til på hjemmeskjerm» (Safari: Del-ikonet; Chrome: ⋮-menyen).

Data lagres lokalt i nettleseren på enheten. Bruk «Last ned sikkerhetskopi» under Aktiviteter jevnlig.
